# Та которую невозможно забыть

Объединённая версия присланного сайта: исходник kniga-istoriy-final, 113 маленьких деталей, 150 медведей/анимаций, ChocoBubble Custom для заголовков и ChocoBubble Text-Regular для текста. История сохранена: вступление, 34 главы, 786 блоков и 29 мест для личных медиа.

## Запуск

Распакуйте весь архив и выполните `python start.py` (Windows: `py start.py`). Откройте http://localhost:8000; мастерская — http://localhost:8000/admin.html.

В мастерской доступны текст, главы, медиа, обложка, фоны, цвета, музыка, подписи, размер и расположение декора, назначения коллекций, история версий, ZIP/JSON экспорт. Раздел «Чтение» показывает анонимные открытия и последнюю страницу при согласии читателя. Это не подтверждение личности или прочтения.

Без Supabase правки и статистика хранятся только в текущем браузере. Для других устройств подключите облако и опубликуйте книгу.

Подробные шаги GitHub → Netlify + Supabase: **DEPLOY.md**. Сверка и ограничения: **docs/Сверка-ТЗ.md**. Список использования всех 263 файлов: **docs/asset-usage.json**.

В site/config.js нет ключей: заполните публичные URL и publishable/anon key своего проекта. Не размещайте service_role или секретные ключи в сайте. SQL-файлы находятся в supabase/.

Проверено: пагинация без потери текста, мобильные ширины, отсутствие наложения декора на текст, загрузки и публикация локально. Реальная облачная публикация и Safari требуют проверки после настройки.
